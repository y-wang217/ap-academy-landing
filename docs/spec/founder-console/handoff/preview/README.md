# Offline UI proof of direction
Open `index.html` in Chrome, Edge, Firefox or Safari. No installs, network requests, cookies, localStorage, secrets, or backend dependencies. All numbers and people are **fictional and explicitly marked as demo**. Mode tabs and "simulate next" are local-only.

This illustrates component sizing, palette, layout, radar motion, mobile collapse, a focal next-lead action and more coherent legibility than the concept painting. It is NOT production-ready code; Claude Code should implement the matching primitives in the selected application architecture, using authenticated source adapters, not copy production fiction from this file.
