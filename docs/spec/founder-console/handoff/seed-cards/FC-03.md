# FC-03 — Truthful console read models and verified weekly-hours metric

> **SEED ONLY:** Create/match a real Notion Dev Requirements card, obtain the actual REQ ID and preserve existing workflow. Do not treat this text as an approved implementation design.

**Suggested priority:** P0  
**Risk:** Medium (designer must re-evaluate against current code and policy)  
**Initial status:** Backlog  
**Blocked by seed cards:** FC-01, FC-02

## Outcome
Panel queries return minimal authorized, provenance-rich data and never display fabricated metrics.

## Scope
- Implement typed server-side read adapters against discovered canonical sources
- Add per-panel status ready/empty/loading/stale/error/unverifiable, timestamps and safe retries
- Compute verified net-new recurring teacher-hours by adopted business evidence; when unavailable report unverified with links
- Deduplicate stable IDs, preserve time-zone boundaries and avoid expensive full-table copies

## Acceptance criteria
- AC1: Real read models exist for leads/follow-ups, trial events, teacher hours, content work, payment status and north-star KPI when supported by current sources.
- AC2: All panels expose source ID and freshness, with unauthorized fields withheld.
- AC3: Net-new weekly hours excludes trials, unpaid/unverified enrollments, duplicate occurrences, one-offs, and reductions are subtracted.
- AC4: Incomplete source evidence yields an explicit "unverifiable" state; never fake zero or approximate paid hours.
- AC5: Partial provider failure does not replace other successful panel data with zeros.
- AC6: Identifiers and joins are stable-record based, not name matching.

## Required test coverage
- T1: Unit tests of 7-day time windows including Toronto DST; positive/reduction/empty/unknown edge cases.
- T2: Integration tests of source adapter fixtures and partial provider failure.
- T3: Data minimization/security tests plus mutation-free read behavior.
- T4: Reviewer verifies counted evidence links and actual implementation file paths.

## Explicit non-goals
- No additional CRM DB or new analytic warehouse without separate design.
